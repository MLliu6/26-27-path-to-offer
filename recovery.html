Path to Offer 本机数据恢复

只读取当前浏览器、当前 GitHub Pages 域名下的存储；密码和数据均不会上传。

返回主站
先不要清除站点数据，也不要在主站点击“创建 / 覆盖”或“跨设备读取”。
本页会优先查找主密文、v1.5 自动保存的最近 3 份旧密文快照、旧版明文 localStorage，以及恢复隔离副本。

1. 扫描结果

支持 raw vault、v1.5 设备备份、紧急存储导出、明文账户导出。

2. 用密码检查候选

密码只参与本机 Web Crypto 解密，不会被保存。建议先输入你原先用于个人账户的密码，再逐项检查。

3. 恢复

只有已成功解密并显示内容统计的候选才能恢复。恢复前，本页会把当前主密文另外隔离保存，不会直接销毁。

没有找到快照时

立即关闭所有该网站标签页，完整复制浏览器配置目录中的 Local Storage\leveldb 文件夹，再做下一步。Edge 常见路径为 %LOCALAPPDATA%\Microsoft\Edge\User Data\Default\Local Storage\leveldb；使用其他 Profile 时将 Default 替换为实际目录。不要先清缓存或让浏览器长时间运行，以免 LevelDB 压缩覆盖可恢复记录。
