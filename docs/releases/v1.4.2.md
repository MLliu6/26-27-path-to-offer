# Path to Offer v1.4.2 — Target Coverage

Release scope: 2026-09-03 target-position and official-source expansion.

- Adds a machine-readable manifest for the user's current applied/main/second-tier target positions.
- Audits every target against the current live domestic + priority feeds on each run.
- Existing live employer rows are kept authoritative and are never replaced by curated leads.
- Missing targets with an employer-owned official URL are added as searchable `curated-target:20260903` leads, explicitly labeled `2027目标岗位·待官网实时复核`.
- Missing targets without an official URL remain visible in the audit as `missing_no_official_url` rather than being fabricated.
- Promotes reviewed employer portals from the target manifest into the official source graph and browser-sweep catalogue.
- Adds an hourly maintenance workflow and an audit artifact/report so live rows automatically replace target leads when the employer source later becomes available.

Safety/provenance boundary: no login, applicant/private API, CAPTCHA bypass, private cookies, or claim that a curated lead is currently open. Official application pages remain the final authority for availability and city.
