# Path to Offer v1.5.0 — 工作台与信源质量升级

## 范围与保留边界

兼容升级自 v1.4.2，不创建替代账户、不改变原密码、账户 ID、vault 路径、加密上下文或本机记忆键。不迁移/重置用户的投递、面试轨迹、简历、面经和准备资料。原有本机账户记忆与解锁机制保留，不把它改成所有访问者可用的免密账户。

## 已定位的问题与处理

| 问题 | 本版处理 |
|---|---|
| 深色背景、卡片、输入框混入绿灰 | 中性黑灰表面，背景 #111113、卡片 #19191c、次级 #222226；强调色与底色分离 |
| 摘要、步骤条和说明重复占空间 | 收起重复说明，搜索和主要操作前置；手机匹配偏好可展开 |
| 更新进度必须填写整张表 | 看板与表格新增快捷状态、日期、跟进日、下一步表单 |
| 空看板列占据宽度 | 可隐藏空阶段；全部、进行中、面试、到期跟进快捷范围 |
| 删除与误改难以补救 | 删除确认、短时撤销、未保存编辑确认；保留原记录字段与历史 |
| 本机密文写入可能乱序，退出时尚未完成 | 加密写入串行化；先捕获对应账户身份，退出前等待保存 |
| 本机仅最新一份密文 | 最近三份密文快照，支持加密设备备份导出/导入；不保存明文密码 |
| 锁定账户被误认为记录消失 | 流程页明确区分锁定账户和访客记录，提供原账户解锁入口 |
| 同名岗位、hash 路由被误合并 | 不同职位 ID 保留；保留 SPA 路由；相同官方记录优先于线索 |
| 目标线索被看成高可信在招职位 | 独立标识、筛选，不授予真实岗位匹配分或官方证据置信度 |
| 线索被简历分数隐藏 | 待核验队列绕开推荐阈值，同时遵守搜索和明确地点筛选 |
| 精确职位 ID 未命中后被同名替代 | 精确 ID 边界匹配、不回退同名；排除线索自匹配 |
| 两小时调度却按小时分片 | 统一两个小时桶，避免偶数分片数下只访问一半分片 |
| 多个爬虫互相覆盖主数据 | 新增独立 supplemental feed；前端合并，失败保留此前观测 |
| 导航、产品卡片被识别成开发岗位 | 排除开发社区、产品路径、业务部门卡片、把整张职位列表当 JD 的误识别 |
| 新兴算力信源一直停在草稿 | 22 个独立扩展招聘面正式接入，并记录逐家采集结果 |

## 信源与采集原则

扩展来源包括曦望 Sunrise、无问芯穹、行云集成电路、原粒半导体、太初元碁、东方算芯、算能、爱芯元智、进迭时空、华为云算法创新 Lab、墨芯、思朗科技、DeepSeek、Kimi、小米、阿里巴巴、Momenta、轻舟智航、昆仑芯、千寻智能、酷睿程、极智嘉。

登记来源不等于获取岗位。只有企业公开页面/公开招聘响应中的具体职位及内容才进入扩展岗位库；不把候选人目标城市、目标届别或历史清单当作官网事实。不登录、不处理验证码、不复用私人 Cookie、不上传简历。扩展巡检是有界抽样，`complete=false`，不声称全量分页。

采集结果：`data/supplemental_source_status.json`；实际观测记录：`data/jobs_supplemental.json`。每两小时选取一个分片，当前 22 个来源分四组轮转。短暂失败保留历史观测及其时间，不直接判定职位下架。原 priority/domestic 采集链仍保留。

## 验证与限制

回归使用虚构账户、虚构简历，不读取用户真实密文内容。覆盖不同 ID 去重、待核验筛选、深色背景、移动端宽度、快捷更新、撤销、备注/面试轨迹/简历保留、退出前保存、刷新账户提示、错误密码不覆盖密文、无明文凭据/简历泄漏、加密备份、新浏览器隔离。

同时保留已有密码学、匹配校准、60,000 条目录、断网/超时回退、旧版看板时间线等测试。临时组装工具在发布前删除；正式工作流独立运行。

浏览器本地数据仍受用户设备和浏览器控制。清除站点数据、无痕退出、更换浏览器或域名不能靠网页自动找回本机密文。需保管备份及原密码；导入备份不会静默覆盖现有本机账户。本版验证代码兼容与合成账户恢复，并不等于远程查看了某位用户电脑中的真实记录。

官网采集不等于岗位现在仍开放或候选人符合申请资格。全量覆盖、自动判断下架、跨设备冲突合并仍需独立支持。未配置的 OAuth 后端不会被伪装成已启用的 GitHub OAuth 登录。
